---
title: "Reading other people's code"
date: 2026-09-20
description: A simple routine for understanding a project you didn't write.
---

Reading code is a skill of its own. Here's the routine I'm using:

1. Start from the README and run the project.
2. Find the entry point and follow one request end to end.
3. Write down every question, then answer them one by one.

It's slow at first, and that's fine.
