I put off learning Git for months. It looked like a wall of commands.
This week I finally sat down with it, and three ideas made it click.

## A commit is a save point

Think of a commit like saving a game. You can always go back to it.

```bash
git add notes.md
git commit -m "Add my study notes"
```

## Branches are just labels

> A branch is a pointer to a commit, nothing more.

Once I read that, branches stopped feeling scary.

## What I'll try next

- Opening my first pull request
- Fixing a merge conflict on purpose, to see what happens
